
# LinguaAI – Language Translator

## Project Overview
LinguaAI is a web-based language translation application
developed using Python and Streamlit.

## Features
- Select source and target languages
- Translate text using an online translation service
- View translation results
- Maintain translation history during the current session
- Download translated text
- Clear translation history

## Technologies Used
- Python
- Streamlit
- Requests
- MyMemory Translation API

## Installation
1. Install Python.
2. Open the project folder in VS Code.
3. Install dependencies:

   pip install -r requirements.txt

4. Run the application:

   streamlit run app.py

## Note
Translation requires an internet connection and availability
of the external translation service. Translation history is
currently maintained for the active app session.

## Conclusion
LinguaAI demonstrates a simple language translation workflow
with an interactive interface built using Python and Streamlit.
